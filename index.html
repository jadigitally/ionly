What is Ionly

For files you'd rather keep private

Ionly is a simple, private file manager for your Mac. Keep your personal files somewhere only you can access — from contracts and financial documents to health records and holiday photos. Protected by a password, your files remain hidden from other people using your computer.

Security

How Ionly actually protects your files

  • Each file is encrypted with AES-256-GCM, using its own key — so one leaked key never exposes everything.
  • Your password never leaves your computer. It's run through scrypt, a slow key-derivation function built to resist brute-force cracking, to unlock your personal encryption key.
  • File names, folders and dates are encrypted too — not just the contents.
  • Tampering or truncating a file is detected automatically, not silently accepted.
  • The app runs a small local server used only by Ionly itself, locked to your own computer — it never accepts a connection from anywhere else.

There is no password recovery. If you forget your password, your files cannot be recovered by Ionly, by us, or by anyone else — that's the trade-off of real encryption.

FAQ

Questions

Can I use it on a shared family or office computer?

Yes — that's exactly what it's for. Each person creates their own password-protected vault on the same machine, and no one can see into anyone else's.

Can anyone else see my files?

No. Your files are encrypted with a key only your password can unlock — not other users on the same computer, not us, no one. If forgotten, see the question below about passwords.

Is this really free?

Yes. Ionly is free to download and use. Security and bug-fix updates will be released as needed.

What happens if I forget my password?

Your vault cannot be recovered. There is no backdoor, no reset link, and no support override — the encryption is real. Choose a password you'll remember, or store it in a password manager.

Does Ionly upload my files to the cloud?

No. Ionly has no cloud sync, no analytics and no crash reporting. The only network activity is an occasional check for app updates — your files never leave your computer.

Which computers does it run on?

macOS today, on both Apple Silicon and Intel Macs. A Windows version is planned.
